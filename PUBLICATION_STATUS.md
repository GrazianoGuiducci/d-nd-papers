## Versioning before formal publication

1. Research drafts, source comparisons and verification evidence remain in their current **private scientific owner**. Do not place confidential sources or unselected manuscripts on a public GitHub branch or public pull request.
2. Only after an explicit authorial selection may an exact qualified manuscript version be transferred here as a **public preprint**, with a stable version, appropriate citation, source status and license. A code-formatting success alone is not scientific validation.
3. A GitHub release, DOI deposit, journal submission, peer review and journal publication are distinct events. Check any repository-to-Zenodo integration before creating a release.
4. Historical public versions are never retrospectively relabeled as though their original content, claims and audience were different. Later corrections preserve dates and provenance.

This document is a factual status update for current readers. It is not a request to erase existing citations or redistribute private scientific notes.
